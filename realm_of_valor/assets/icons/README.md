# Map Icons for Epic Fantasy Map

This directory should contain PNG icon files for the epic fantasy map markers.

## Required Icons:

- `pin-default.png` - Default marker icon
- `pin-sanctum.png` - Capital/Sanctum icon (e.g., castle, tower)
- `pin-city.png` - City/Town icon (e.g., buildings, houses)
- `pin-harbor.png` - Harbor/Dock icon (e.g., ship, anchor)
- `pin-dungeon.png` - Dungeon/Ruin icon (e.g., skull, cave)
- `pin-artifact.png` - Artifact/Treasure icon (e.g., gem, crown)
- `pin-waypoint.png` - Waypoint icon (e.g., flag, signpost)
- `pin-trail.png` - Trail icon (e.g., path, footsteps)
- `pin-enemy.png` - Enemy icon (e.g., sword, shield)
- `pin-quest.png` - Quest icon (e.g., scroll, book)

## Icon Specifications:

- **Size**: 32x32 pixels (PNG format)
- **Style**: Fantasy/medieval theme with transparent background
- **Colors**: Should work well on dark map background

## Temporary Solution:

Until you create custom icons, the app will use Google Maps default markers.
You can create simple colored circles or download free fantasy icons from sites like:
- Flaticon.com
- Icons8.com
- Game-icons.net

## Example Icon Creation:

You can create simple colored circles using any image editor:
1. Create 32x32 pixel image
2. Draw a colored circle with transparent background
3. Save as PNG
4. Use different colors for different categories
